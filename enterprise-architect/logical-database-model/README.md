# Logical Database Model for Enterprise Architect

Файлы в этой папке описывают логическую модель реляционной базы данных EduPlatform.

- `EduPlatform-Logical-Database-Model.qea` — готовый проект Enterprise Architect.
- `EduPlatform-Logical-Database-Model.xmi` — резервный вариант для импорта в Enterprise Architect, если нужно импортировать модель в другой проект.
- `EduPlatform-Logical-Database-Model.puml` — резервный PlantUML-вариант для просмотра/перегенерации.

## Что внутри `.qea`

Открой файл `EduPlatform-Logical-Database-Model.qea` в Enterprise Architect и раскрой:

`EduPlatform` → `Logical Database Model` → `Logical Database Model - relational tables`

Диаграмма сделана одной страницей/одним полотном. В таблицах показаны поля и отметки `PK`/`FK`; физические типы данных не указаны. В модель включены только реляционные таблицы, без MongoDB-коллекций чатов и сообщений.

Сформировано таблиц: 57. Связей на диаграмме: 118.
